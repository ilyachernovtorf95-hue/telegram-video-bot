# Telegram Video Knowledge Bot

Telegram-бот для сохранения и разбора видео из YouTube, TikTok, Instagram, Threads и VK.

## Что делает бот

1. Получает ссылку в Telegram.
2. Скачивает видео через `yt-dlp`.
3. Отправляет видео обратно в Telegram в максимально практичном качестве до 1080p.
4. Если файл превышает лимит Telegram Bot API, режет его на части **без перекодирования**, чтобы не ухудшать качество.
5. При наличии `GEMINI_API_KEY` загружает исходное видео в Gemini Files API и анализирует ролик целиком: речь, визуальный контекст и текст в кадре.
6. Возвращает:
   - краткую смысловую выжимку;
   - главные мысли;
   - важные факты и детали;
   - практические действия;
   - важное из визуала;
   - ключевые моменты с таймкодами;
   - утверждения, которые стоит проверить;
   - тематические теги;
   - полную транскрипцию в `.md`-заметке для Obsidian.
7. Если Gemini временно недоступен или бесплатная квота закончилась, автоматически включает локальный резерв: `whisper.cpp tiny` + детерминированная extractive-выжимка.

## Почему архитектура такая

Ранее бот запускал `llama.cpp` + Qwen внутри Railway. На малом CPU/RAM это приводило к зависаниям, таймаутам и перезапускам контейнера. Новая архитектура не держит локальную генеративную LLM в Railway: основной смысловой и мультимодальный анализ выполняет Gemini, а Railway отвечает за загрузку/отправку видео, оркестрацию и локальный аварийный fallback.

Это снижает RAM, размер контейнера и вероятность зависаний.

## Railway Variables

Обязательно:

```env
TELEGRAM_BOT_TOKEN=...
```

Для качественного AI-разбора:

```env
GEMINI_API_KEY=...
```

Дополнительно:

```env
GEMINI_MODELS=gemini-3.7-flash,gemini-3.5-flash-lite
MAX_TELEGRAM_VIDEO_MB=49
MAX_ANALYSIS_VIDEO_MB=1900
WHISPER_LANGUAGE=ru
LOCAL_AI_THREADS=1
TIKTOK_COOKIES_B64=
```

`GEMINI_API_KEY` создаётся в Google AI Studio. Бот рассчитан на модели, у которых есть Gemini Developer API Free Tier. Если бесплатная квота модели недоступна для конкретного проекта/региона или временно исчерпана, бот не ломается, а переключается на локальный fallback.

### Приватность Gemini Free Tier

По условиям Google, контент запросов бесплатного Gemini Developer API может использоваться для улучшения продуктов Google. Не отправляйте через бесплатный API конфиденциальные или чувствительные видео, если это для вас неприемлемо.

## TikTok с авторизацией

Для роликов, требующих входа, можно задать `TIKTOK_COOKIES_B64` — base64 от Netscape cookies-файла. Секрет хранится в Railway Variables и не должен попадать в GitHub.

## Надёжность

- один URL подтверждается Telegram до тяжёлой обработки, чтобы рестарт Railway не отправлял одно видео многократно;
- основной AI и локальный fallback изолированы: сбой Gemini не ломает скачивание видео;
- Gemini-файл удаляется после анализа;
- версии ключевых runtime-компонентов зафиксированы;
- normal video splitting использует stream copy (`-c copy`) и не ухудшает качество;
- при временном `409 Conflict` от Telegram polling бот ждёт завершения конкурирующего экземпляра и повторяет запрос.

## Запуск

Railway собирает проект по `Dockerfile` и запускает `python bot.py`. Дополнительный локальный `llama.cpp` больше не требуется.
