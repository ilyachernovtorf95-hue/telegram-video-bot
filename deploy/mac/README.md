# Запуск бота на MacBook Air с Apple Silicon

Этот вариант использует тот же Dockerfile, код Telegram-бота и настройки качества
видео/AI-анализа, что и облачная версия. Новая облачная регистрация не нужна.
Пока MacBook включён и подключён к интернету, бот получает сообщения через
Telegram long polling; открывать входящие порты или настраивать роутер не нужно.

## Первый запуск

1. Установи и **открой** [Docker Desktop для Mac с Apple Silicon](https://docs.docker.com/desktop/setup/install/mac-install/).
   Для личного использования он бесплатен. Docker может попросить пароль Mac
   при установке. Аккаунт Docker для обычного личного использования не нужен.
2. Открой «Терминал» на Mac. Вставь команды:

```sh
git clone --branch deployment/local-mac --single-branch https://github.com/ilyachernovtorf95-hue/telegram-video-bot.git
cd telegram-video-bot
cp .env.example .env
chmod 600 .env
open -e .env
```

3. В открывшемся файле замени `TELEGRAM_BOT_TOKEN` и `GEMINI_API_KEY` на
   существующие значения из настроек Railway, затем сохрани файл. Если в
   Railway были заданы дополнительные переменные для VK/YouTube, перенеси и их.
   Ключи остаются только на твоём Mac. Не отправляй `.env`, ключи или токены в
   чат и GitHub. Если исходных ключей у тебя нет, получи их у BotFather и
   в Google AI Studio; не публикуй их в скриншотах.
4. Прежде чем запускать, выключи старый сервис Railway, если он снова стал
   активен. Одновременный опрос Telegram двумя копиями с одним токеном даст
   ошибку `409 Conflict`.
5. В Терминале из папки `telegram-video-bot` запусти:

```sh
sh deploy/mac/start.sh
```

Первая сборка включает FFmpeg, Chromium, локальную модель Whisper и помощник
для YouTube, поэтому загрузка и сборка могут занять некоторое время и место
на диске. Проверь сообщения `PRIMARY: starting responsive Telegram bot` и
`Responsive Telegram runner started`, затем отправь `/start` и ссылку на
небольшое видео. Отдельно проверь длинное видео, воспроизведение на iPhone,
AI-разбор, полную транскрипцию и файл заметок.

## Чтобы бот оставался на связи

- Держи MacBook подключённым к сети питания и интернету, с открытой крышкой.
  В «Системные настройки → Аккумулятор → Параметры» включи предотвращение
  автоматического сна при подключённом питании и выключенном дисплее.
  Дисплей может выключаться; компьютер должен оставаться бодрствующим.
- В Docker Desktop → Settings → General включи автоматический запуск при входе
  в macOS. В `compose.yaml` уже настроен перезапуск бота после запуска Docker.
- Закрытие крышки обычного MacBook усыпляет его и останавливает ответы бота.
  При поездках, выключении Mac, пропаже сети или электричества бот будет
  недоступен до восстановления работы компьютера. Этот способ не обеспечивает
  круглосуточную доступность без постоянно работающего устройства.

## Проверка и обслуживание

В папке `telegram-video-bot`:

```sh
docker compose ps
docker compose logs --tail=80 bot
```

Обновление кода:

```sh
git pull --ff-only origin deployment/local-mac
sh deploy/mac/start.sh
```

Остановка бота: `docker compose stop bot`. Повторный запуск без сборки:
`docker compose up -d bot`. Не удаляй файл `.env`: в нём хранятся ключи.

Ограничения качества: сам код не меняется, но YouTube может блокировать запросы
даже с домашнего IP, а AI-анализ зависит от доступности и квот Gemini.
